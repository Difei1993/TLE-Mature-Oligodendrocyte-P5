# GitHub publication notes

This public GitHub repository contains the **code-only** P5 analysis package, published with the author's approval on 2026-10-09. The 52 author-written scientific scripts are distributed under the MIT License; their content is unchanged from the audited code-only package.

No third-party raw data, 35 withheld derived data/figure artifacts, Figure SVG inputs, or two excluded mixed-source signature catalogs are redistributed. The original data and archived checkpoints must be obtained under the respective providers' terms, as described in `README.md` and `docs/data_inputs.md`.

The author should independently ensure that public software licensing is consistent with any applicable institutional or collaborative intellectual-property obligations. The initial version v1.0.0 was formally released on GitHub and archived on Zenodo with version-specific DOI [10.5281/zenodo.23266083](https://doi.org/10.5281/zenodo.23266083). Version v1.0.1 extends that release with three display-only helpers and corrected version metadata. The prior DOI remains specific to v1.0.0; a new version DOI may be recorded only after the matching deposit is verified. The companion manuscript remains pending submission.

The scripts' historical outputs were **not regenerated** during packaging or GitHub publication. See `docs/known_limitations.md` and `docs/source_gaps.md` for reproduction boundaries.
